# 🏭 «Честный Знак: Линия»

Браузерная idle/clicker-игра про внедрение обязательной маркировки (DataMatrix / «Честный знак»)
на производственной линии. Документ с гейм-дизайном и обоснованием механик — [DESIGN.md](DESIGN.md).

## Запуск

**Через node-сервер (рекомендуется):**

```
node server.js              # или: npm start
```

Игра откроется на **http://localhost:8080** (порт — переменная `PORT`; если занят, сервер сам найдёт свободный).
Рекорды при таком запуске хранятся на сервере в `data/records.json` (API: `GET/POST/DELETE /api/records`).

Без сервера (двойной клик по `index.html`) игра работает так же, но рекорды — в localStorage браузера.

**Тесты:**

```
npm test                   # или: node tests/run.js
```

## Управление

| Действие | Как |
|---|---|
| Доложить продукт на линию | Клики по зоне **«🏭 Производство»** или кнопка **«➕ Продукт»** в панели этапов (клик по продукту в зоне производства паспорт не открывает) |
| Заказать коды DataMatrix в ЧЗ | Кнопка «📦 Заказать 200 кодов ЧЗ» (генерация ~15 секунд) |
| Наклеить этикетку вручную | Кнопка «🏷️ Наклеить этикетку», пока продукт в зоне наклейки |
| Проверить код | Камера **считывает 2 кода/с** (апгрейды ускоряют). Без неё коды не проверяются |
| Отбраковщик | Возвращает брак на переклейку; иногда **пропускает** его (−15% цены); снижается модельным рядом и «Двухступенчатой» |
| Улучшения | Клик по **шестерёнке 🔧** в карточке оборудования — модальное окно прокачки (покупка на ходу) |
| Выполнять контракты | Центральная колонка: соберите партию под контракт — она **закрывается автоматически** |
| Докинуть брак на переклейку | Клик по лотку «🗑️ Брак» |
| Продать на рынок партией | Кнопка «📤 Продать на рынок» (с сервером — автоматически, пока нет контракта) |
| Паспорт продукта | Клик по коробке (вне зоны производства): код DM, даты маркировки/годности, сорт, смаз/повреждения |
| Чит-панель | Кнопки на стартовом экране |

**Поток:** подача продукта → заказ кодов ЧЗ → печать этикеток → наклейка → **проверка камерой** → **модуль «Отбраковка»** → **📦 Склад** → контракты заказчиков (только для продукта вашего завода) или рынок партиями.

## Обязательные механики

- **Льготный период — 45 секунд**: продукция продаётся без DM, штрафы и брак за чтение кода не считаются (работает и для рулона этикеток: до маркировки линия не встаёт из-за него). Только просрочка срока годности уходит в утиль сразу.
- **Час Ч** — дедлайн партии; к нему должны работать принтер + камера + сервер, иначе «Бизнес закрыт».
- После введения маркировки **немаркированный товар не продаётся** — только перемаркировка; требование ЧЗ растёт 0% → 100%.
- **Аудит** через 5 минут после дедлайна: победа при доле регистрации ≥ 90% и неотрицательном балансе. Дальше — песочница.
- **Банкротство**: баланс в минусе **10 секунд** — и кредиторы забирают предприятие (успели вернуться в плюс — отменяется).
- Просроченный товар — в утиль; «Наценка» (серия продаж без брака, до ×1.8) сбрасывается любой неудачной маркировкой.

## Продукты и скорость линий

| Продукт | Цена | Срок хранения | Множитель линии |
|---|---|---|---|
| 🥫 Консервы | 14 ₽ | 36 мес | ×1.0 (эталон) |
| 🧴 Шампунь | 12 ₽ | 24 мес | ×1.36 |
| 🥛 Молоко | 9 ₽ | ~1 мес (портится быстро!) | ×2.42 |
| 🧃 Соки | 8 ₽ | 9 мес | ×3.06 |
| 🥤 Напитки | 6 ₽ | 6 мес | ×5.44 |

Скорость линии = **квадрат отношения цен** (в 2 раза дешевле − в 4 раза быстрее). Множитель применяется к потоку, печати, наклейке и считыванию камеры.

## Маркировка

- **Типография** (150 ₽): печатает DM прямо на продукт — проклеивать не нужно, каждый код ×3.
- **Свой принтер** (800 ₽): печать этикеток (база 3.6 шт/с, апгрейды быстрее), человек-наклейщик (база 0.5 + 0.25/ур, до 100 ур.). Режимы переключаются в любой момент.
- **Рулон и буфер**: рулон 90 (аппликатор 200→600), буфер печати виден отдельно; **рулон < 15 — после введения маркировки линия ждёт печати**.
- **Принтер-аппликатор** (2500 ₽): клеит сам со скоростью печати **в 2 раза ниже**, но + человек — общая проклейка = сумма.
- Улучшения принтера: модельный ряд **PrintMark100…** (20 уровней), «Качество печати» (−0.1% брака/ур), «Ускоренная подача в рулон», «Автозамена рулона», «Ёмкость рулона». При обрыве ленты протяжка уничтожает ~40% кодов.

## Камера

- Скорость считывания **2 кода/с** (модельный ряд ReaderDM100… +20%/модель; «Промышленное освещение» +25% и убирает вспышку; вспышка видна на непрочитанном продукте).
- Пропуск кода, «Хардкор»-события и прочее — как раньше.
- **Мыльный DM**: камера с ПО «Чёткость» ловит в брак; **проскочивший** дефект «обнаруживается» покупателем — **возврат = штраф на полную стоимость** (шанс 50%).

## Цех, склад и прокачка

- **Партии**: заказчик появился — партия назначается под контракт (размер = остаток контракта; без контракта — автоматический, по производительности). Собранная партия **сама закрывает контракт**.
- **Склад**: «Склад: расширение» (+30 мест/ур), «Климат-контроль» (рекламации −1%/ур, база 10%), «Отгрузка без потерь» (+2% цены/ур). Полный склад останавливает подачу.
- **Качество продукта** (10 ур.): дорогие сорта — премиум ×1.3, люкс ×1.7, элитный ×2.2 — выпадают всё чаще.
- **Автозаказ кодов ЧЗ** (Цех): порог = **запас на 100 секунд работы линии** (1 шт/с → 100, 2 шт/с → 200).
- «Разгон конвейера», «Вторая линия» (видна: две дорожки + «×2»), «Сервисная служба», «Турбо-конвейер».
- Все улучшения стоят **в 3 раза дешевле** заявленного. Прокачка открывается **модальным окном** по клику на шестерёнку.

## Здоровье оборудования

Каждый модуль изнашивается; ремонт тем дороже, чем хуже состояние; при полной поломке — **«Купить новое»**. Сломанный модуль замедляет линию и работает вручную. Апгрейды: «Лазер», «Автоочистка», «Сервисная служба».

## Режимы

🟢 Лёгкий (700 ₽, 12 мин) / ⚪ Стандарт (400, 10) / 🔴 Хардкор (150, 8, штрафы ×1.5) / **∞ Бесконечный** (500, без дедлайна: требование ЧЗ растёт по времени, 10 минут до 100%).

## Рекорды

На титуле: товар, произведено, промаркировано, дата и счёт. **Счёт = (промаркировано ×3 + произведено) × множитель сложности** (лёгкий ×0.7, стандарт ×1, хардкор ×3, бесконечный ×1.5). Кнопка «🗑 Сбросить рекорды» рядом.

## DataMatrix — реальная генерация

Библиотека [datamatrix-svg](https://github.com/namotco/datamatrix-svg) (MIT, `vendor/datamatrix.min.js`) генерирует настоящий ECC200; при недоступности — встроенный canvas-fallback. Хороший код — чёткий; брак печати — размазан («мыльный»); после повторной переклейки — с царапинами.

## Тесты

Запуск: `node tests/run.js` (49 тестов: ядро, производственный поток, контракты, настройки/баланс).
Каждый файл `tests/*_test.js` — независимый сюит в изолированном контексте игры (заглушки DOM, без браузера):
`module.exports = function (h) { h.test('описание', function () { ... h.assert(условие, 'сообщение'); }); };`
Хелперы: `h.loadGame()` (свежая сессия: `Game`, `CFG`, `genDM()`, `products()`), `h.runScenario(game, seconds, opts)` (тики с авто-кликером/покупками/модалками; `opts.clicks/buyCycle/hook/noEvents/noContracts/startIr` и др.).
